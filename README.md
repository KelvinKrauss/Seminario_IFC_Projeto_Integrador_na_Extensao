## 📂 Conteúdo do Repositório

O repositório está estruturado em 4 arquivos principais em LaTeX, correspondentes aos seguintes tópicos:

### 1. 🧮 Processo de Ortogonalização de Gram-Schmidt
* **Descrição:** Estudo do método de Gram-Schmidt para ortogonalizar um conjunto de vetores em um espaço com produto interno, permitindo a construção de bases ortogonais e ortonormais a partir de uma base inicial.

### 2. 📐 Fatoração QR
* **Descrição:** Análise da decomposição de uma matriz em um produto de uma matriz ortogonal ($Q$) por uma matriz triangular superior ($R$). O seminário aborda a relevância dessa técnica para a resolução de sistemas lineares sobredeterminados e problemas de mínimos quadrados.

### 3. 🛡️ Reflexões de Householder
* **Descrição:** Exploração das transformações lineares conhecidas como Reflexões de Householder. Demonstra-se como essas matrizes simétricas e ortogonais realizam reflexões em torno de um hiperplano e como são empregadas na computação estável da Fatoração QR.

### 4. 🔄 Rotações de Givens
* **Descrição:** Investigação das Rotações de Givens (também conhecidas como transformações lineares planares). O seminário detalha como essas matrizes realizam rotações em subespaços bidimensionais para introduzir zeros de forma seletiva em posições específicas de uma matriz, sendo ideal para matrizes esparsas.
